# Guarantee Passport

PIRESAAO / ACIDHUB KOS · KEM / KEK compatible product projection

Guarantee Passport is a chat-first product view for understanding whether a guarantee remains current and decision-relevant. It translates governed evidence complexity into four plain-language questions: what is known, what changed, what is not established, and who needs to decide.

## Golden fixture

`Rural Property Guarantee GP-001` starts stable for a credit decision backed by rural property. A new environmental or registry condition is observed, so the product reaches **Review required**. The application never autonomously approves the guarantee.
